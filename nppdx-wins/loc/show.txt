   105  // (CopyConstBorder; NPP has no batched border), then 8 bit -> float and the normalization on the N planes at once, as

   109  // The bordered planes start at a multiple of BORDERED_ALIGNMENT bytes. nppiCopyConstBorder_8u_C3R launches one kernel
   110  // when its destination is a multiple of 12 bytes (4 RGB8 pixels), and two or three otherwise (measured with NPP 13.1;
   111  // the source does not matter). Every plane is a multiple of 12 bytes, so every plane is aligned like the first, and
   112  // the pipeline is N + 5 kernels in every mode and process, wherever the allocation lands. Without the alignment the
   113  // residue was that of the address cudaMalloc returned: the same in every process of the main mode (residue 8: 2N + 5
